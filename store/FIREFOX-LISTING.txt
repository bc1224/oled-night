OLED Night turns website backgrounds true black while keeping text readable and images in their original colors. Made for OLED displays, and works on other screens too.

• Automatic dark mode, full recolor, deepen blacks only, invert, or off for each site.
• Per-site brightness, contrast, and optional image dimming.
• Schedule and Alt+Shift+D shortcut.
• Settings backup and optional broken-site reports.

OLED Night does not record or save your browsing history. No ads, analytics or tracking. Website access is used to recolor pages locally. Your settings, including per-site preferences, use your browser's sync storage; these are preferences, not a record of visits.

Firefox's optional browsing-activity permission only covers sharing the current site's domain in a bug report. It does not enable history tracking. In 0.6.41, preview the scrubbed technical diagnostics, optionally describe the problem, then choose Submit issue. Our Cloudflare-hosted reporting service creates a public GitHub issue directly; no GitHub sign-in or draft is required. Automatic diagnostics exclude page text, entered values, URL paths, cookies and screenshots. Declining permission leaves dark mode working normally.

GitHub retains submitted public issues. The service retains only temporary request hashes, daily counters and issue links for up to 49 hours, with a daily salted address hash for abuse limits; it does not store report bodies or raw network addresses. Full local report downloads can contain short text snippets and site addresses; review them before sharing them yourself. Keep personal information out of descriptions.

Free and open source. Firefox desktop 142 or later. Some sites may need a different mode or to be turned off.
