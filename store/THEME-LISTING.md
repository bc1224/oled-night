## Store listing
- **Summary:** True-black Chrome theme: black tabs, toolbar, address bar and new-tab page. Pairs with the OLED Night extension.
- **Description:**

  Makes Chrome itself true black, the kind of black that turns OLED pixels off: the tab strip, toolbar, address bar, bookmarks bar and new-tab page.

  It's the companion to the OLED Night extension, which makes websites black. Chrome doesn't let extensions change its own window, so this part is a theme. Use them together for a fully black browser.

  No permissions, no code, no data collected. Open source: https://github.com/bc1224/oled-night
