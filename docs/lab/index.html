What a release has to prove

State coverage

Move between siblings, tab through controls, open overlays, update content and disable/re-enable. A resting screenshot is only one state.

Visual evidence

Approved screenshots, contrast and boundary checks, and paint samples during transitions. Baselines are reviewed explicitly.

Responsiveness

Menu paint latency and event-loop stalls measured alongside a native baseline. Real-site smoke checks supplement the local cases.

This lab cannot prove saved-password filling, CAPTCHA token generation or every third-party site. Those still need targeted live verification.
