# OLED Night 0.6.31 audit

## Findings and fixes

The App Store Connect ratings failure is a global paint-classification bug. Live Chrome inspection of 0.6.30 showed a 4px rating track mapped to `rgb(10,10,13)` and its 33.3% fill mapped to black. The fill was still present and had the correct width, but could not be distinguished from the track. The broken-site report had no text contrast findings because it did not inspect data graphics.

0.6.31 recognizes empty nested horizontal and vertical bar fills from their original computed geometry and track paint. This works without Apple-specific classes or host rules, including narrow layouts. Neutral fills become light grey; colored fills retain hue and alpha. Widths, zero values, native control values, ordinary panels and standalone separators are preserved. Generated fills inside semantic progress, meter and image containers receive the same treatment.

The audit also reproduced neutral SVG chart bars, lines and labels disappearing. Accessible SVGs labeled as charts, ratings, histograms, distributions, progress or graphs now retain visible data marks while their full plot background stays dark. Other SVG artwork keeps its existing handling. Unlabeled or differently localized chart labels may still need additional evidence and coverage.

Reports now include `lowContrastGraphics` for recognized data marks with contrast below 3:1. These entries contain element descriptions, contrast and override markers, not chart labels or data values. Inactive outlines no longer receive unnecessary overrides.

Streaming pages without color transitions were paying for subtree transition guards on every batch. Those batches now skip the guards and animation enumeration. SVG and generated-content batches retain the conservative path. In an isolated two-second fixture, the focused check improved from 82/119 extension/page-only ticks to 93/117, with worst frame interval falling from 36ms to 30ms. These are synthetic samples, not a measurement of the user's Amazon dropdown delay. The full suite passed its churn gate at 88/120 ticks and a 37ms worst interval.

## Verification

- The original source failed six initial graphics checks. The fixed source passes neutral, colored, generated, vertical and SVG graphics cases, zero values, dynamic width changes, disable restoration and graphic diagnostics.
- Chrome: 208 checks passed locally before the final narrow-bar addition; CI passed 210 checks on the exact release commit, including the narrow bar and system-theme cases.
- Firefox: 78 checks passed using the packaged 0.6.31 extension.
- All 11 unit test files passed; Firefox package validation: zero errors, warnings or notices.
- Existing regressions cover Gmail dropdowns and email bodies, Amazon images and menus, Shopify protected authentication components, Bitwarden overlays, YouTube native themes, image mattes, container boundaries, gradients, frames, shadow roots and settings.

This was a targeted live App Store Connect inspection plus controlled browser regression audit, not a fresh 50-site live survey. The updated package has not yet been observed on the user's live Apple page. The reported real Amazon 5–10 second sort delay and a real Bitwarden saved-credential fill remain unconfirmed. No new permissions; companion theme remains 1.0.2.
