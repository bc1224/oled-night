# OLED Night live Chrome site audit — 2026-09-29

## Scope and method

One focused visual and interaction pass on 12 pages across 11 domains in the user's Chrome profile. The installed extension reports **0.6.18** on every inspected page. The local **0.6.22** build was not installed, so this is an audit of the installed version, not acceptance testing of the packaged fixes. Chrome control was used for screenshots, representative menu/search actions, and read-only DOM/computed-style checks. Counts are snapshots, not load-time or CPU measurements. Image elements with `naturalWidth === 0` outside the viewport can be lazy-loaded; they are not automatically failures. No same-profile extension-off timing baseline was available.

## Priorities and limits

1. **P0 Gmail missing email text and search suggestions:** the circled email content is present in the DOM but painted white on white by dark-scheme `WindowText`. Local 0.6.22 scopes `color-scheme: light` to Gmail's authored message body and darkens the light suggestion panel behind recolored text. Both pass local Chrome regression checks; live Chrome still has 0.6.18.
2. **P0 Amazon Grocery:** live 0.6.18 still hides product photos. Local 0.6.21 has a targeted fix, but the installed extension has not been updated to prove it.
3. **P1 Logo/icon preservation:** Wikipedia wordmark and Stack Overflow logo become effectively invisible on black. Audit SVG currentColor and dark raster/SVG logos on converted headers.
4. **P1 Amazon sort responsiveness:** user-reported delay remains open. Native select opens in the audit, but browser-control round-trip time is not a valid interaction latency measurement. A same-profile A/B run with OLED Night toggled is needed before assigning CPU cost.
5. **P2 Other prior reports:** iFixit product-page text and Glimbo native select blowout were shown in user screenshots; this pass did not reopen those exact states.

The extension can plausibly slow large changing pages because it marks and restyles thousands of elements (10k on Amazon search, 19.5k on Ralphs). This audit does not quantify that cost or show that OLED Night caused a specific website's load or dropdown delay. The two user-provided Amazon JSON reports contain styled counts (4,990 and 10,061) and low-contrast samples, but no timing fields.

## Gmail follow-up on installed 0.6.22

The user then installed 0.6.22 and supplied new screenshots. Live Chrome inspection confirmed that Gmail's native-dark shell made OLED Night choose `crush`, which left the white `.nH.a98.iY` reading pane and authored email tables white. The 0.6.22 `color-scheme: light` rule restored `WindowText` paragraphs, but did not darken their email canvas. Its hard-coded dark `.gssb_m` search panel had black `.gssb_a .asor_b` text and muted `.asor_e` text; the outer `.gssb_e` remained white. These were paired color failures, not missing content. The local 0.6.23 fix recolors the full Gmail reader and search regions together, and its Chrome fixture checks both surfaces and text. Live 0.6.23 validation remains pending installation; no Gmail interaction timing was measured.
