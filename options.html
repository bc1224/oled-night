Sites

How each site is treated. Sites not listed follow the main switch.

On (automatic)
Recolors light sites; on sites that are already dark, only deepens their blacks.
Full recolor
Always recolors, even if the site looks dark already.
Deepen blacks only
Leaves everything alone except pushing the darkest greys to true black.
Invert
For apps drawn on a canvas (spreadsheets, design tools). Flips the whole page, images flipped back.
Off
Never touch this site.

Make Chrome itself black

This extension darkens websites, but Chrome doesn't let extensions change its own window. The free OLED Night theme does that part: it turns the tab bar, toolbar, address bar and new-tab page black.

Keyboard shortcut

Currently not set turns the current site on or off.

Experimental

A few apps build parts of the page as "closed" components that extensions can't see into, so those parts stay light. This makes them reachable. Rarely, a site may behave differently; turn it off if something breaks. Takes effect on newly loaded pages.

Backup

Save all settings and site rules to a file, or load them on another browser.
